# System Decomposition

## Modules

- User Management
- Attendance Management
- QR Code Generation & Validation
- Geolocation Service
- Reporting & Analytics
- Notification & Messaging
- Admin Dashboard

## Components Responsibilities
**User Management:**

- Registering students, lecturers, and administrators  
- Managing login and logout  
- Controlling access based on user roles  
- Allowing users to update their profiles  

**Attendance Management:**

- Recording when a student checks in or out 
- Linking attendance to specific classes  
- Making sure attendance is only recorded once per session  
- Keeping accurate attendance records

**QR Code Generation & Validation:**

- Generating a unique QR code for each class session  
- Validating QR codes when students scan them  
- Setting expiration times for QR codes  
- Preventing reuse or sharing of QR codes

**Geolocation Service:**

- Capturing the student’s GPS location during attendance  
- Checking if the student is within the correct class location  
- Detecting possible fake or spoofed locations  
- Supporting location-based attendance rules  

**Reporting & Analytics:**

- Generating attendance reports  
- Showing trends and patterns in attendance  
- Allowing reports to be downloaded (e.g., PDF or CSV)  
- Supporting decision-making for lecturers and Notification & Messaging

**Notification & Messaging:**

- Sending confirmations when attendance is recorded  
- Notifying students about missed classes  
- Sending updates about schedules or system changes  
- Supporting communication through email or messaging platforms  

**Admin Dashboard:**

- Managing users and their roles  
- Monitoring attendance records  
- Managing courses and class sessions  
- Viewing reports and system analytics  
- Handling issues within the system
