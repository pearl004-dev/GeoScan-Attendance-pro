### Explanation of Relationships
-	The React Frontend communicates with backend services through API requests. 
-	The Authentication Component validates users before access is granted. 
-	The Attendance Management Component coordinates attendance processing. 
-	The QR Verification Component validates QR code submissions. 
-	The Geolocation Validation Component verifies location authenticity. 
-	The PostgreSQL Database stores and retrieves all attendance-related information. 
### Justification
The UML Component Diagram helps visualize the organization of the system and the interaction between major components. The decomposition of the system into separate components improves maintainability, modularity, scalability, and ease of testing.
