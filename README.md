# Geo Scan Attendance Pro
 Geo Scan Attendance Pro is a smart attendance management system designed to automate and secure the process of tracking student or employee attendance. The system uses QR code scanning combined with geolocation verification to ensure that users can only mark attendance when they are physically present at the designated location.

When a user scans a generated QR code, the system captures their real-time location and validates it against a predefined area. This helps prevent proxy attendance and improves accuracy. The platform also stores attendance records digitally, allowing administrators to easily monitor, manage, and generate reports.

The project aims to provide a fast, reliable, and user-friendly solution for institutions and organizations seeking to modernize their attendance systems.
