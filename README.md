# Geo Scan Attendance Pro
Geo Scan Attendance Pro is a smart attendance management system that leverages QR code scanning and geolocation verification to ensure accurate and secure attendance tracking.

The system allows users to scan a dynamically generated QR code while simultaneously verifying their real-time location. Attendance is only recorded if the user is within an authorized location, reducing the risk of proxy or fraudulent check-ins.

This project is designed to help institutions and organizations modernize their attendance processes by providing a reliable, efficient, and user-friendly digital solution. It also enables easy record management and reporting for administrators.
